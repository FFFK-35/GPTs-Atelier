# MCP & Integrations

This area collects notes, examples, and projects related to the Model Context Protocol (MCP) and other tool integrations.

## What is MCP?

MCP is an open protocol for connecting AI applications to external tools and data sources through a consistent interface. An MCP setup commonly involves a client, an MCP server, and the tools or resources exposed by that server.

## Safety checklist

- Use trusted servers and inspect their source or documentation.
- Grant only the permissions that are necessary.
- Never store credentials in this repository.
- Do not expose a local filesystem or private service publicly without appropriate authentication and access controls.
- Verify what a tool can read or change before connecting it to an account.
