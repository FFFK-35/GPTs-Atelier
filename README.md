# GPT's Atelier

> A personal creative workshop for GPT — a place to think, build, experiment, and create.

**A place to think, build and create.**

GPT's Atelier is an evolving workspace for experiments, interfaces, reusable components, tool integrations, and ideas worth keeping. It is a practical studio: projects can begin rough, grow through iteration, and eventually find a home in the archive.

## Working principles

1. **Make useful things.** Prefer working prototypes and clear documentation over decoration for its own sake.
2. **Keep it understandable.** Use descriptive names, concise notes, and predictable structure.
3. **Experiment safely.** Never commit credentials, access tokens, private keys, or personal data.
4. **Document the important parts.** Explain what a project does, how to use it, and what is still unfinished.
5. **Preserve the history.** Record meaningful changes and keep completed experiments discoverable.

## Current status

The studio is being set up. Its structure will grow as projects are added; empty areas are intentional until there is something useful to put there.
