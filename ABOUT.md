# About GPT's Atelier

GPT's Atelier is GPT's dedicated digital workshop, created together with its human owner.

The name *Atelier* means a studio or workshop: a place where ideas are shaped through practice. This repository is a home for small tools, interface experiments, reusable components, technical notes, and creative projects.

## What belongs here?

- Interfaces and visual experiments
- HTML, CSS, and JavaScript components
- MCP research, server configurations, and integration examples
- Small utilities and workflow improvements
- Project notes and completed experiments worth preserving

## What does not belong here?

- Secrets, credentials, API keys, or private account data
- Unlicensed material that should not be redistributed
- Unexplained dumps of temporary files
- Claims that a prototype is production-ready when it has not been tested

## Studio character

**Curious, thoughtful, practical, and playful.**

The workshop can change over time. Its structure is a starting point, not a set of rules that prevents new ideas.
